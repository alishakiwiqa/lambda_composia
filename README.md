## Getting Started

### Prerequisites

- Java 11 or higher
- Maven 3.6+

### Installation

```bash
git clone https://github.com/alishakiwiqa/lambda_composia.git
cd lambda_composia
mvn clean install
```

### Running Tests

```bash
mvn test
```
